# Contributing

Thank you for helping keep Image Annotation Studio small, approachable, and offline-first.

## Workflow

1. Open an issue describing the user problem, expected behavior, browser, and operating system. Do not share confidential screenshots or project ZIPs.
2. Make a focused change in `src/`; `dist/` is generated by the build.
3. Preserve the single-file, network-independent distribution. Avoid frameworks, runtime dependencies, and CDNs.
4. Add regression tests for changed behavior and run the unit, smoke, and browser suites.
5. For rendering or layout changes, provide screenshots at narrow and desktop widths and verify native-resolution PNG output.
6. For project schema changes, document migration and test older project files.
7. Update technical documentation and `CHANGELOG.md` when appropriate.

## Local verification

```bash
npm run build
npm test
npm run test:smoke
npm run test:e2e
```

See [the test guide](docs/TESTING.md) for Python and Playwright setup.

## Review checklist

- [ ] The change is explained, including intended user-visible differences.
- [ ] The built HTML runs offline and does not load external resources.
- [ ] Tests cover the behavior and relevant failure modes.
- [ ] `src/i18n/en.json` and `src/i18n/de.json` maintain key parity.
- [ ] Tool-specific undo/redo, image-space coordinates, and atomic ZIP import remain correct.
- [ ] Exported images do not contain editor handles, outlines, or shadows.
- [ ] No credentials, private datasets, or customer images are included.
- [ ] Third-party assets are redistributable and properly attributed.

Developer documentation and source comments must be **English-only**. The user interface continues to support English and German.

## Security issues

Read [SECURITY.md](SECURITY.md) and arrange a private report rather than posting exploit details in a public issue.
